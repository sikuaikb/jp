## 1. 总览

| 维度 | CSV | Website |

| L1 大类 | 50 | 50 |

| Website 独有路径 | — | 424 |

**主要结论**

1. **CSV 数据明显偏旧或抓取不全** —— 50 个 L1 中有 40 个 Web 端规模更大；其中电阻器、IC、晶体振荡器、电缆电线管理等 8 个 L1 偏差超过 100%。
2. **类目重组** —— Digi-Key 已对部分类目做了搬迁/重命名（详见 §4），这是 CSV 路径与 Web 不匹配的主要原因。
3. **「套件」类目大量下架** —— CSV 中以「XX 套件」结尾的小类目几乎全部在 Web 上消失或被合并。

## 6. 风险与建议

### 6.1 数据可信度评估

| L1 | 可信度 | 说明 |
|---|---|---|
| 电阻器 | ❌ 严重失真 | 漏抓最大子类，缺 174 万条 |
| 集成电路（IC）| ❌ 严重失真 | 所有 L2 子类几乎只抓到表层，缺 52 万条 |
| 晶体，振荡器，谐振器 | ❌ 严重失真 | 振荡器子类完全缺失，缺 43 万条 |
| 电缆，电线 - 管理 | ⚠️ 偏差较大 | 大量 L2 子类未抓到 |
| 五金件，紧固件，配件 | ⚠️ 偏差较大 | 大量 L2 子类未抓到 |
| 网络解决方案 / 计算机设备 / 工业用品 | ⚠️ 偏差较大 | 整体 L1 缺数 |
| 连接器，互连器件 | ✓ 部分可用 | 主要 L2 都有，但库存数已增长 30%+ |
| 电容器 / 电缆组件 / 电位计 / 风扇 / 电感器 / 电源 - 板安装 / 测试与计量 | ✓ 较新 | L1 总量差异 < 15% |

### 6.2 建议

1. **立即重抓 IC、电阻器、晶振 三个 L1 的全部 L2 子类**，按 §5 列表补全。
2. **更新分类映射表** —— 处理 §4.1 的 9 条类目搬迁、§4.2 的二极管/晶体管层级压缩。
3. **清洗 CSV 中的 3 条 URL 脏数据**：
   - `https://www.digikey.cn/zh/products/detail/gedore-tools-inc/KL-0186-1612-H/24665504`
   - `https://www.digikey.cn/zh/products/detail/nexperia-usa-inc/74HC173PW-118/1230142`
   - `https://www.digikey.cn/zh/products/detail/nxp-usa-inc/SSTUA32S865ET-551/1158344`
4. **下次抓取需关注**：以「套件」结尾的小类目大量被合并/下架，需要重新梳理。

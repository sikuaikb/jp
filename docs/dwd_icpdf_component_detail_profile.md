## 11. 对下游 DM / 数据服务的建议

1. **主键唯一无重，直接可做 upsert 源表**。如要做"去重事实表"，可把 `md5file` 作为 PDF 维度粒度，配合 `partno/brandid` 建立双边关系表。
2. **建 3 张维度表**：
   - `dim_brand`（`brandid`, `brandshort`），行 1,249；
   - `dim_category`（`categoryid` → 3 级分类）；
   - `dim_pdf_file`（`pdf_file_id`, `md5file`, `filename`, `page`, `filesize`, `foldpath`, `foldpath2`, `big_img`），~250 万行。
3. **建事实宽表**：
   - `fact_partno_pdf`：`(id, dt, partno, brandid, pdf_file_id, createtime, updatetime)` 作为最小化高频访问事实。
   - `fact_partno_params`：只筛 `prajson2 IS NOT NULL` 的 ~605 万行，把 `prajson2` 展平成 `partno × param_name × param_value` 的 EAV 结构，用于参数搜索。
4. **图像资源层**：`pin_diagram / schematic_diagram / package_pad_diagram` 数据稀疏（<2%），建议单独建 `dwd_icpdf_component_media` 表或作为子 JSON，不在主宽表扩列。
5. **URL 协议补齐**：应用侧统一 `https://` + 字段；或加一层视图把 4 个 URL 自动前缀化。
6. **文本索引**：`note` / `note_cn` / `all_info` 可直接进全文索引；`partno` 做倒排 + 首字符分片。
7. **替代料关系**：`pdf_replace_partno_arr` 展开后可做 `partno_a -> partno_b` 替代料图。
8. **分区重跑**：主键表 upsert 语义下，任何分区可由 `scripts/clean_all_partitions.sh` 原地重跑，不会产生重复。

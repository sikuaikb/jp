# connector · 得捷源摸底笔记

日期：20260622  schema：v1.4.30（`tmp/connector_schema.xlsx`）

## 1. 邻近品类边界
- 线缆类（同轴/光纤/模块化以太网电缆、D-Sub 电缆）不纳入 gate，避免把线材当连接器本体。
- USB 闪存/U 盘、USB Hub、光纤收发器模块归其他 L1，不进 connector gate。
- `存储卡` 是存储介质卡本身，不是卡座连接器；DIMM/SODIMM 插座在 `直列式模块插座`。

## 2. 源端坑点
- DigiKey `category` 粒度粗：外壳/触头/配件/组件常拆成多个叶子，classify 需 `category_in` 合并。
- `USB、DVI、HDMI 连接器组件` 混装 USB/HDMI/DVI，需 `note_cn_regexp` 专规拆分。
- 端子系统 `端子接线系统` 以模块/接地块为主，螺钉/弹簧/栅栏细分信号弱，v1 以 pluggable fallback。

## 3. 候选属性键（阶段 3 输入）
- 触点数量、间距、安装方式、额定电流/电压、IP 等级、Mounting Type 等（prajson KV 待 gap 探针）。

## 4. 数据量
- gate 白名单 category 并集约 **95** 个叶子（v2 补全遗漏叶子，v1 为 64）。
- 全库 DigiKey 参数表约 770 万行；connector L1 CSV 总量 **2,447,784**；gate v2 命中约 **243.5 万** SKU（有意排除 ~1.3 万端子耗材/套件）。
- 与 244 万差距 **~1.3 万**，对应 `端子块标记条/跳线/配件/连接器套件/香蕉配件` 等纯耗材，不纳入清洗范围。

## 5. 明确排除（不进 gate）
- `同轴电缆（射频）`：线缆，非连接器本体
- `光纤电缆`：线缆
- `单芯电缆（连接线）`：线缆
- `D-Sub 电缆`：线缆
- `视频电缆（DVI，HDMI），视频数据线`：线缆
- `模块化/以太网电缆（RJ45，RJ11）`：线缆
- `扁平柔性电缆（FFC、FPC）`：线缆
- `USB 闪存驱动器`：存储设备，非连接器
- `USB 集线器`：USB Hub，非连接器
- `光纤收发器模块`：光模块，归 optoelectronics
- `存储卡`：存储介质卡，非卡座连接器
- `端子块标记条`：配件
- `端子块跳线`：配件
- `端子配件`：配件
- `配件`：端子块配件子类
- `连接器套件`：套件/杂项
- `香蕉和尖头连接器配件`：耗材配件
